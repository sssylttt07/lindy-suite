# Lindy Suite — Standalone Editors for AI Role-Play Content

Standalone HTML applications (open directly in a browser, no install) for editing role-play content, developed by **Lin**. They are the desktop/mobile "app editions" of the plugins published in [lindy-tavo-plugins](https://github.com/sssylttt07/lindy-tavo-plugins).

## Apps

| File | App | Version | What it does |
|---|---|---|---|
| `Lindy Pro V0.6.3-gre.html` | **Lindy Pro** | 0.6.3 | Full-featured mask/panel editor (desktop & mobile). Edits status panels, value bars, collapsible sections; Tavo mode exports beautification regex. |
| `Lindy Air V1.1.6-gre.html` | **Lindy Air** | 1.1.6 | Mobile-friendly, entry-level mask editor with embedded HTML styling (status bars, bubble cards, collapsibles). Optimized for Rubii users; no regex export. |
| `LinWork Pro V0.4.9-gre.html` | **LinWork Pro** | 0.4.9 | Full-featured character-card writer with JSON browser/editor; Tavo-mode export. |

## Usage

Open the HTML file in any modern browser. Data stays local — no server, no upload.

## Ecosystem

```
Lindy Pro (app)  ──►  Lindy / LinMask (Tavo plugins)
Lindy Air (app)       (mobile / Rubii-friendly branch)
LinWork Pro  ──►  LinChar (Tavo plugin, AI card writer)
```

See the [lindy-tavo-plugins](https://github.com/sssylttt07/lindy-tavo-plugins) repository for the plugin versions.
