# Changelog

## 0.6.3 / 1.1.6 / 0.4.9 — 2026-11-05

### Lindy Pro 0.6.3

Full-featured mask/panel editor (desktop & mobile). Edits status panels, value bars, and collapsible sections; Tavo mode exports beautification regex.

### Lindy Air 1.1.6

Mobile-friendly, entry-level mask editor with embedded HTML styling (status bars, bubble cards, collapsibles). Optimized for Rubii users; no regex export.

### LinWork Pro 0.4.9

Full-featured character-card writer with JSON browser/editor; Tavo-mode export.

### Note on saved settings

Browsers keep panel settings locally. If an old panel style still shows up in the preferences after an update, reset that panel once to start from the current defaults.

### Verified

- All script blocks pass `node --check`: LinWork Pro 14, Lindy Pro 2, Lindy Air 1.
